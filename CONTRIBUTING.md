# Contributing

Thanks for looking. This is a **public evidence repo**, not an open research dump.

## Humans

1. Open an issue describing the change.  
2. Keep PRs small and focused.  
3. Do not add proprietary data, keys, or the JF manuscript PDF.  
4. Run `python repro.py` and `python reproduce_headline.py` before push.

## Coding agents (Cursor / Claude Code / Codex / OpenAI / cloud agents)

Follow [`AGENTS.md`](AGENTS.md) and [`VIBE_CODING.md`](VIBE_CODING.md).

Pattern we want reviewers to see:

```
intent → agent draft → human gate → CI → public surface
```
